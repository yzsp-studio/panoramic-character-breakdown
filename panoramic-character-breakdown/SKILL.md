# 角色蓝图工坊 — 工业级角色全景设定图生成器

将角色从"一段文字描述"升级为"一张工业级全景设定大图"，所有细节一图汇总，直接用于 AI 视频角色一致性参考、LoRA 训练、IP 衍生开发。

**与现有 Skill 的分工**：
- `film-assets` → 单模块资产（角色卡 / 道具视图 / 场景概念图），按需单出
- `film-shot` → 影视分镜 / 剧照设计，镜头语言驱动
- **本 Skill** → 系统化角色全景分解，一站式产出全套角色设定大图

**本 Skill 能力范围**：
- ✅ 角色全景分解图（八大层级全部或部分）
- ✅ 角色锚定图（AI 视频一致性专用）
- ✅ 角色设定板（创意提案 + 风格展示）
- ✅ LoRA 训练数据集准备指导
- ✅ 道具/武器分解图（作为角色资产的一部分）
- ✅ 场景-角色融合参考

## ★ 单图全景模式（推荐默认）

**核心理念**：将三视图、面部特写、表情集、服装拆解、道具特写、头身比全部集成在一张 16:9 综合大图中。一张图 = 一个角色的完整设定蓝图。

### 6 区布局标准（16:9 横版，深灰 #2A2A2A 背景，白色细线分区）

```
┌──────────────────────────────────────────────────────────────┐
│  ZONE A (左上)       │  ZONE B (中上·最大区)    │ ZONE C (右上) │
│  THREE-VIEW 三视图   │  MAIN REFERENCE 主视觉   │ FACIAL DETAIL │
│  正面/侧面/背面全身  │  3/4角度半身像           │ 面部细节特写   │
│  + 头身比标尺        │  角色最典型状态的英雄图   │ 4-5个圆形放大  │
│  + 身高标注          │  (含妆效/战损/光影)      │ (眼/鼻/嘴/额)  │
├──────────────────────┼──────────────────────────┼───────────────┤
│  ZONE D (左下)       │  ZONE E (中下)           │ ZONE F (右下)  │
│  EXPRESSIONS 表情集  │  COSTUME BREAKDOWN       │ KEY PROPS      │
│  4-6个半身表情       │  服装材质拆解            │ 道具特写       │
│  含渐进式妆效变化    │  引导线标注材质/破损     │ 3-4个关键道具  │
│  (轻伤→重伤递进)    │  面料纹理/做旧/血迹     │ 含磨损/使用痕迹│
└──────────────────────────────────────────────────────────────┘
```

### 各区域内容规范

**ZONE A — 三视图区**：
- 3 个全身立绘：正面(0°)、侧面(90°)、背面(180°)
- **中性表情**（无笑无怒），**标准站立姿势**，**双手自然下垂**，手中不拿任何东西
- 旁边设置头身比标尺（如 1H~7.5H），顶部标注身高（如 180cm）
- 底部标注 "HEAD:BODY = 1:X"，标注肩宽/腿长等体型特征数据
- **背景**：纯白色或纯灰色，无任何干扰元素
- **光线**：均匀柔和的正面光，无明显阴影
- 服装必须完整展示从上到下（含鞋子），可见褶皱走向、材质纹理、花纹图案
- 所有固定配饰（项链/耳环/手表/戒指/头饰）必须清晰可见
- 所有永久性特征（疤痕/痣/纹身/发色/发型）必须清晰可辨

**ZONE B — 主视觉区（面积最大）**：
- 腰部以上半身像，3/4 角度
- 展示角色最典型/最有记忆点的状态（如战场状态、妆效最完整的状态）
- 电影感打光（如伦勃朗光、半脸阴影）
- 这是整张图的"英雄镜头"——第一眼视觉焦点

**ZONE C — 面部细节区**：
- 4-5 个圆形/方形放大特写，引导线连接到主视觉
- 必须包含：
  - 眼部特写：瞳色、虹膜、睫毛、鱼尾纹、泪膜反光、眼眶红肿等
  - 鼻颊特写：鼻型、毛孔质感、肤色纹理、灰尘/泥渍
  - 口颌特写：唇形、下颌线、胡茬/胡须、干裂/血迹
  - 额颞特写：额纹、太阳穴、发际线、发丝质感
  - （可选）耳部、疤痕、痣等特殊标记放大

**ZONE D — 表情集区**：
- 4-6 个胸像（头+肩），2×2 或 2×3 网格
- 每个表情用**肌肉状态**描述而非情绪词（如 "furrowed brow, eyes squeezed" 而非 "sad"）
- **渐进式妆效变化（关键特色）**：
  - 从剧本/分镜表提取角色的视觉变化时间线
  - 表情1 = 最轻妆效（如轻灰尘），到表情N = 最重妆效（如满脸血污+泥灰）
  - 每个表情面板底部可标注妆效阶段（如 "轻伤" "重伤" "濒死"）

**ZONE E — 服装拆解区**：
- 全身立绘 + 4-6 个引导线标注框
- 每个标注框放大展示一个服装细节：领口/口袋/扣子/腰带/面料纹理/袖口
- 必须标注：
  - 材质名称（如 "olive-drab wool"）
  - 做旧/损伤程度（如 "fraying at cuffs" "dust in folds"）
  - 特殊工艺（如铆钉/缝线/补丁）
- 从剧本中提取的服装破损细节必须体现

**ZONE F — 道具特写区**：
- 3-4 个独立道具渲染
- 每个道具展示其使用状态（磨损/锈蚀/刻痕/沾灰）
- 道具选择基于角色在故事中的关键场景道具
- 深灰背景，清晰可辨

### 单图全景的剧本联动规则

当用户提供了分镜表/剧本时：
1. **自动提取角色视觉细节**：扫描剧本中该角色出现的所有镜头，提取疤痕、伤口、血迹、泥灰、服装破损、道具磨损等描述
2. **构建渐进式变化时间线**：按故事时间顺序排列该角色的视觉状态变化
3. **映射到表情集妆效递进**：表情集的 4-6 个面板对应角色从"最初状态"到"最终状态"的妆效变化
4. **服装/道具损伤标注**：将剧本中提及的破损细节写入 ZONE E/F 的引导线标注中

## STEP 0: 判断配置级别 & 收集信息

### 0a. 输入来源

询问用户是否有角色参考图：
- **有参考图** → 用 `hub_read_media` 分析，提取完整特征（脸型/发色/发型/肤色/体型/服装/配饰/特殊标记）
- **无参考图** → 收集文字描述（姓名、性别、年龄、职业、外貌、服装、性格关键词）

### 0b. 配置级别选择

用 Q&A 组件询问用户：

| 级别 | 产出内容 | 制作时间 | 适用场景 |
|------|---------|---------|---------|
| **基础配置** | 六视图锚定图 + 简化设定板 | 快速 | 短视频、单集短剧 |
| **进阶配置** | 八视图锚定图 + 完整设定板 + 表情集 + 服装展示 | 中等 | 多集短剧、系列视频 |
| **顶级配置** | 全景式八层完整分解 + LoRA 数据集指导 | 完整 | S+级系列短剧、IP开发 |

### 0c. 风格与媒介确认

- **媒介风格**：写实 / 动漫 / 3D（默认写实）
- **视觉风格**（可选，影响设定板主视觉）：从八种视觉风格中选择
  → 详细风格参考见 `cinematic-grammar-glossary` Skill 的视觉风格速查表
- **背景风格**：纯白（锚定图默认）/ 深灰（角色卡默认）/ 自定义

⏸ 等待用户确认后再继续。

## STEP 1: 构建角色身份卡片（Subject Identity Lock）

这是整个分解图的**基石**——一份固定的角色描述卡片，逐字粘贴到后续所有生成 prompt 中。

### 角色身份卡片格式

```
【角色身份卡片 — Subject Identity Lock】
姓名: [角色名]
性别/年龄: [性别], [年龄]岁
脸型: [具体描述]
发型/发色: [具体描述]
肤色: [具体描述]
身高: [精确数值, 如"180cm"]
头身比: [精确比例, 如"1:7.5（7.5头身）"]
体型特征: [详细描述, 如"宽肩窄腰, 肌肉线条明显, 锁骨突出"]
服装: [从内到外完整描述, 含褶皱/材质/花纹, 如"亚麻白衬衫(自然褶皱, 粗织纹理), 藏青色羊毛西裤(细条纹暗纹, 膝盖处轻微压痕)"]
鞋子: [具体描述, 如"黑色牛皮德比鞋, 微磨损鞋头"]
配饰: [所有固定配饰, 如"银色链条项链/左耳单钉耳环/右手无名指戒指"]
永久性特征: [疤痕/痣/纹身/胎记等不可移除的身体特征]
性格关键词: [3-5个制造记忆点的词, 如"外冷内热/嗜酒如命"]
配色系统: 主色[色名+HEX] 60% / 辅色[色名+HEX] 30% / 点缀色[色名+HEX] 10%
```

**关键规则**：
- 用户提供参考图时，从 `hub_read_media` 分析结果逐项提取，不遗漏
- 无参考图时，从用户文字描述构建，缺失项主动询问
- 此卡片在后续**每一次** image agent 调用中都必须完整重复（子 agent 无状态）

### 媒介风格锁（必须写入每次调用）

| 媒介 | Prompt 必须显式写 | 同时排除 |
|------|-----------------|---------|
| **写实** | `Medium: hyper-realistic photography. Photorealistic, live-action.` | `NOT anime, NOT cartoon, NOT 3D render` |
| **动漫** | `Medium: 2D anime illustration style. Hand-drawn anime aesthetic.` | `NOT photoreal, NOT 3D render` |
| **3D** | `Medium: stylized 3D render, CG animation style.` | `NOT photoreal, NOT anime` |

## STEP 3: 各层级通用生成规范

### 生成参数（所有层级共用）

| 参数 | 规范 |
|------|------|
| **模型推荐** | **优先使用 Banana 和 image2（角色一致性最佳）；如不可用，允许回退到同能力模型** |
| 角色一致性 | 每次调用都完整重复角色身份卡片（STEP 1 的 Subject Identity Lock） |
| 参考图 | 用户提供了参考图时，必须将文件路径传给 image agent |
| 批量策略 | 同层级内一次性批量生成，不逐张交替 |
| 画质修饰 | 8K, sharp focus, high detail |
| 文字标签 | 锚定图/技术图不添加任何文字标签；设定板可添加简短注释 |
| 比例 | 单图模式 16:9（横版）；多图模式按内容自适应 |

### 锚定图专用约束（Layer 1）

- **背景**：纯白色或纯灰色，无任何干扰元素（不能有墙壁、地板、家具、植物等任何背景元素）
- **姿势**：标准站立姿势，双手自然下垂（不能有任何动作，手里不能拿任何东西）
- **表情**：中性表情（无笑无怒，面部肌肉完全放松）
- **光线**：均匀柔和的正面光，无任何明显阴影（不能有逆光、侧光、伦勃朗光等任何光影效果）
- **视角**：平视（eye-level），相机高度与人物腰部至胸部齐平
- **比例**：正常人体比例，禁止夸张拉伸或缩小
- **目的**：越"证件照式"越有效——越标准化，AI 识别越准确

#### ✅ 锚定图必须包含的信息

| # | 必须包含项 | 说明 |
|---|-----------|------|
| 1 | **清晰的正面五官** | 眼睛、鼻子、嘴巴、脸型，全部清晰可辨 |
| 2 | **清晰的侧面轮廓** | 鼻子高度、下巴线条、后脑勺形状 |
| 3 | **完整的全身比例** | 身高、头身比、腿长、肩宽，必须标注具体数值 |
| 4 | **完整的服装（含褶皱/材质/花纹）** | 从上到下包括鞋子，标注面料材质、褶皱走向、花纹图案 |
| 5 | **所有固定配饰** | 项链、耳环、手表、戒指、头饰等佩戴型配饰 |
| 6 | **所有永久性特征** | 疤痕、痣、纹身、发色、发型等不可移除的身体特征 |
| 7 | **体型特征** | 肩宽/腰围比例、肌肉线条、身材轮廓等结构性特征 |

#### ❌ 锚定图绝对不能包含的信息

| # | 禁止项 | 原因 |
|---|--------|------|
| 1 | **任何表情** | 必须是中性表情，无笑无怒，避免 AI 锁定特定情绪 |
| 2 | **任何动作** | 必须是标准站立姿势，双手自然下垂，避免姿态干扰识别 |
| 3 | **任何道具** | 手里不能拿任何东西（武器/道具等归入 ZONE F 道具区单独展示） |
| 4 | **任何背景元素** | 不能有墙壁、地板、家具、植物等，只允许纯白/纯灰底 |
| 5 | **任何光影效果** | 不能有逆光、侧光、轮廓光、投射阴影等，只允许均匀柔和正面光 |

> **铁律**：锚定图的核心目标是**提取角色的纯视觉身份信息**。任何表情、动作、道具、背景、光影都是干扰信号，会降低 AI 视频生成时的角色一致性识别准确度。

### 侧面提示词规范（防镜像翻转）

- 不使用 left / right / 左 / 右 / mirror / 镜像 等对称方向词
- 用摄影机物理移动的动态描述替代：
  - 第二格：`Side Profile View`
  - 第三格：`The lens orbits to another different side of the character`
- **原理**：AI 模型对"左/右"对称语义理解弱，使用摄影机运动语言能生成真正不同的角度

### 面板数量强约束

模型对复杂内容容易自行增加面板数量，必须多重锁定：
1. 正向声明：`exactly N panels`
2. 反向禁止：`NOT more than N, NOT N+1, NOT N+2`
3. 兜底警告：`If you generate more than N instances the entire image is WRONG`
4. Negative prompt 追加：`more than N items, extra panels, duplicate views`

## STEP 4: 用户确认检查点

每完成一个层级后，展示生成结果，等待用户确认再进入下一层级。

**检查要点**：
- 角色身份是否一致（面孔/服装/发型/发色跨视图不漂移）
- 媒介风格是否统一（不能出现半写实半动漫）
- 细节还原是否准确（配饰/特殊标记/材质）
- 比例是否正常（无夸张变形）

如有问题，针对性调整 prompt 重新生成该层级，不需要重做已通过的层级。

⏸ 每个层级完成后暂停，等待用户反馈。

## 快速参考

```
三种配置级别：
  基础: Layer 1-2（锚定图 + 设定板）→ 短视频/单集短剧
  进阶: Layer 1-4（+ 表情集 + 服装拆解）→ 多集短剧/系列

  L4 服饰拆解层: 分层拆解 + 变装 + 材质特写

  L7 色彩系统层: 多光照色标 + 完整配色

铁律：
  1. 角色身份卡片（Subject Identity Lock）逐字重复到每次调用
  2. 身份卡片必须含：身高、头身比、体型特征、服装褶皱/材质/花纹
  3. 媒介风格锁必须显式声明，整组锁同一种
  4. 锚定图越"证件照式"越有效
  5. 锚定图必须包含：正面五官/侧面轮廓/全身比例/完整服装(含鞋)/固定配饰/永久性特征

  8. 不用 left/right，用摄影机运动语言

  10. 模型推荐：优先 Banana / image2，如不可用允许回退
```

## 定稿门控 — Production-Ready Gate

角色设定图生成完毕后，**必须通过以下6项检查才能标记为「定稿」**。
任一项标注为"待定/未确定"→ 必须提醒用户风险：

> ⚠️「角色[XX]的[具体项]还没定稿。如果现在开始出分镜，
> 后续改动会导致**所有含该角色的镜头全部返工**。建议现在定稿。」

用户确认"就这样先做" → 记录 warning 继续；用户补充 → 更新设定图后再标记定稿。

### 检查清单

| # | 检查项 | ❌ 不合格示例 | ✅ 合格示例 |
|---|--------|-------------|-----------|
| 1 | 服装每个部件有**具体名称/型号** | "军服""深色外套" | "昭五式军服""M65野战夹克" |
| 2 | 头部装备有**型号+可见特征** | "帽子""头盔" | "九八式略帽，四片帽垂れ" |
| 3 | 面部特征有**正面+负面清单** | "看起来凶" | "塌鼻梁/小眼/薄唇；无疤痕/无痘印" |
| 4 | 徽章/领章/肩章**标注完毕** | 未提及 | "红色襟章，金色军衔星" |
| 5 | 配色有**具体色值或精确描述** | "深色" | "芥末卡其色(#8B7D3C)" |
| 6 | 道具/武器有**具体型号** | "步枪" | "三八式步枪，带刺刀" |

### 典型教训

角色设定只写"二战日军制服，网状钢盔"→ 出了40+分镜后发现应该是"昭五式军服+九八式略帽"
→ 全部返工。**这6项检查本可以在开始出分镜前就拦住。**

## 敏感内容应对 — Safety Filter Fallback

军事/战争/暴力题材的角色设定图可能触发模型安全过滤器。

| 阶段 | 可能被拦截的情况 | 应对策略 |
|------|----------------|---------|
| **i2i 编辑** | 原图含军事人物/武器被拦截 | 改用 t2i 重新生成，将原图的构图/色彩/姿势全部用文字描述 |
| **t2i 生成** | prompt 含极端暴力描述被拦截 | 降低暴力描述强度，用临床化语言替代渲染性语言 |
| **参考图** | 历史照片作为参考被拦截 | 改用已生成的 AI 图（非真实照片）作为参考 |

**核心原则**：被拦截时不要反复重试同一张图/同一句 prompt，**立即切换路径**。

## 编辑决策 — i2i vs t2i 判定

用户要修改已有角色设定图时，根据指令用词判断操作方式：

| 用户说 | 操作 | 含义 |
|--------|------|------|
| "在这张图基础上改/修改这张图" | **i2i 编辑** | 以该图为底图，只改指定部分 |
| "重做/重新画/换一版" | **t2i 重新生成** | 从头生成，原图仅作构图参考 |
| "参考这张但不要一样" | **t2i + 风格参考** | 新生成，原图为风格/构图参考 |

**铁律**：用户说"在XX基础上改"时，**必须用那张原图作为 i2i 输入**，
不能偷偷重新生成一张"差不多的"。用户指定了哪张图就是哪张图。
