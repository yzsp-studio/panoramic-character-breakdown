# Layer 2: 角色设定板规范

> **何时 read**：生成角色设定板 / 角色设计板时。

## 核心定义

角色设定板 = 角色的"视觉说明书" + "创意展示板"。
与锚定图的最大区别：**首先是给人看的，其次才是给 AI 看的**。

## 标准组成结构

### 主视觉区（占比 50%）

- 角色最具代表性的高质量全身立绘
- 包含背景和氛围元素，体现角色的性格和所处环境
- 姿势应展现角色的气质（不像锚定图那样标准站姿）
- 可应用视觉风格（赛博朋克/港片/IMAX/自然写实等）

### 技术参考区（占比 30%）

- 简化版三视图或四视图（正/侧/背/3-4）
- 主要服装和配饰的展示
- 基础配色方案色卡

### 风格参考区（占比 15%）

- 2-3 张参考风格描述（光影风格和质感说明）
- 注明参考的影视风格方向

### 文字说明区（占比 5%）

- 角色姓名、年龄、职业、性格简介
- 关键设计理念说明
- 不超过 100 字

## 设定板排版

- **横版 16:9**，网格布局，信息层次清晰
- 主视觉图要具有冲击力
- 技术参考区简洁明了
- 深灰或深蓝背景（与锚定图的纯白区分）

## 顶部信息区

包含角色的名字、身份、年龄，以及 3-5 个能制造"矛盾感"与"记忆点"的性格关键词。
这些词会直接影响 AI 生成的表情和姿态。

示例关键词：`外冷内热` / `嗜酒如命` / `温柔但致命` / `天真但腹黑`

## 配色系统展示

包含 6-8 个精选色块（主色60%、辅色30%、点缀色10%），
并明确标注肤色和发色。色块按照实际使用比例排列。

## AI 视频中的特殊用法

- 可直接作为**风格锚定图**使用，确保整个视频的美术风格统一
- 用于生成角色的**关键帧海报**和**预告片素材**
- 配合角色锚定图使用，可以在保证一致性的同时，提升画面的艺术表现力

## 八种视觉风格速查

可用于设定板主视觉区的风格定调：

| 风格 | 关键词 |
|------|--------|
| 赛博朋克 | neon-lit, rain-slick streets, holographic ads, magenta + cyan |
| 港片夜雨 | wet pavement, moody street lamps, anamorphic blur, teal shadows |
| IMAX 史诗 | wide vistas, dramatic backlight, 70mm grain |
| 对称糖果色 | symmetrical composition, pastel palette, centered subject |
| 北欧极简 | desaturated palette, cold light, vast negative space |
| 70s 胶片 | warm Kodak film grain, sun-flared, muted earth tones |
| 黑色电影 | high-contrast B&W, venetian blind shadows, low-key |
| 自然写实 | available light, handheld feel, documentary aesthetic |

详细 prompt 关键词组 → 见 film-shot skill 的 `references/visual-styles.md`
