# Layer 8: 风格规范层

> **何时 read**：生成跨媒介风格化指南、角色谱系图、造型演变稿时。

## 核心目标

补充专业规范，确保角色在不同媒介和场景下都能完美融入。
这是"适应性"的关键——角色不只活在一种风格里。

## 跨媒介风格化指南（Style Guide）

### 核心规则

定义角色在不同风格下的**转换规则**和**核心特征保留方案**：

```
在任何风格化转换中，以下特征必须100%保留（不可简化/省略/替换）：
1. [面部核心特征，如"剑眉+丹凤眼+左眉尾疤痕"]
2. [标志性配色，如"主色深蓝+强调色金"]
3. [标志性配饰/元素，如"右手黑色皮手套"]
4. [发型核心结构，如"右侧长刘海遮半眼"]

以下特征可按风格需要适度调整：
- 服装细节复杂度（Q版可简化褶皱和花纹）
- 身体比例（Q版允许2-3头身）
- 材质写实度（动漫风可简化为色块+高光）
- 面部细节密度（Q版可省略毛孔/细纹）
```

### 标准风格转换矩阵

| 目标风格 | 比例调整 | 面部处理 | 服装处理 | 配色处理 |
|---------|---------|---------|---------|---------|
| **2D 动漫** | 保持原头身比 | 简化为动漫五官，保留识别特征 | 保留设计，简化材质为色块+线条 | 饱和度略提升 |
| **3D 写实** | 保持原比例 | 增加毛孔/皱纹/SSS | 增加布料物理/缝线/磨损 | 自然色温 |
| **Q版/萌化** | 2-3 头身 | 放大眼睛，简化五官，保留标志特征 | 极度简化，保留标志性设计元素 | 高饱和，柔和 |
| **水墨风** | 保持原比例 | 线条勾勒，留白处理 | 水墨晕染，简化为大色块 | 降低饱和度，墨色为主 |
| **像素风** | 可调整 | 简化为最小辨识像素 | 简化为色块 | 有限调色板 |

### Prompt 写法

```
[目标风格] style adaptation of [角色名],
MUST PRESERVE: [列出不可更改的核心特征],
style-appropriate adjustments: [列出允许调整的部分],
[媒介风格锁关键词],
character identity must remain immediately recognizable
```

### 排版规范

- **横版 16:9 单图**，同一角色在 3-5 种风格下的半身像横排
- 最左为"原版/基准"，右侧为各风格变体
- 每个面板下方标注风格名称
- 引导线标注"保留"和"调整"的元素

## 角色谱系比例图（Character Lineup）

### 多角色项目专用

将所有主要角色放在同一画面中，展示相对比例关系：

- 所有角色脚底对齐同一基准线
- 按身高从矮到高（或按剧情重要性）排列
- 标注每个角色的身高数值
- 用虚线标注肩高和头顶位置
- 统一姿势（标准站姿）和统一光线

**Prompt 写法**：
```
character height lineup chart, 
[角色A名+身高] [角色B名+身高] [角色C名+身高] 
standing side by side on the same baseline,
heights labeled above each head, 
dotted horizontal lines marking shoulder and head heights,
neutral standing pose, white background,
technical character reference sheet, exactly [N] characters
```

## 造型草图/设计稿（Design Sketches）

### 记录设计演变过程

展示从初稿到定稿的设计迭代：
- 3-5 个不同阶段的草图
- 标注每个版本的设计意图和放弃原因
- 最终版高亮标注

**用途**：
- 备选方案展示
- 创作过程记录
- 团队沟通参考

## 发型设计图

### 复杂发型拆解

从不同角度分解发型结构：
- 正面/侧面/背面的发丝走向
- 编发/盘发的层次和固定方式
- 刘海的精确覆盖范围
- 发饰/发带的位置和样式

**排版**：中心头部正面，周围 4-6 个角度的局部放大。

## 禁止清单（Do-NOT-Generate List）

明确列出该角色**绝对不能出现**的元素和表现方式：

```
该角色禁止出现：
- ❌ [具体禁止项，如"露齿大笑"/"赤脚"/"摘下手套"]
- ❌ [违反设定的元素，如"现代电子设备"（古装角色）]
- ❌ [OOC行为，如"暴力行为"（温柔角色）]
```

将此清单写入后续所有生成的 Negative prompt 中。
