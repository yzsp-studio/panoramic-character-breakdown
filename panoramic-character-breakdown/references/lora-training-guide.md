# LoRA 训练数据集准备指南

> **何时 read**：用户选择顶级配置，需要 LoRA 训练数据集输出时。

## 核心原则

全景式分解图 = 角色的"数字孪生 DNA 数据库"，提供最完整、最精确的特征样本。
专属角色 LoRA = 角色的"身份识别模型"，将分解图中的所有特征编码成 AI 能永久记住的权重。
两者结合 = 给 AI 植入角色的"基因记忆"，而不是简单的"图像参考"。

## 数据集准备（最关键的一步）

### 数据集规模

**15-25 张图**（太少特征不全，太多会过拟合）

推荐构成：
| 类别 | 数量 | 来源层级 |
|------|------|---------|
| 全身多视图 | 8 张 | Layer 1（六/八视图锚定图拆分） |
| 头部转面和表情 | 6 张 | Layer 3（头部转面图 + 表情集拆分） |
| 服装和材质特写 | 4 张 | Layer 4（服装分层 + 材质特写） |
| 细节特征图 | 2 张 | Layer 5/6（手部特写 + 道具特写） |

### 图片预处理

1. **统一裁剪**：1024×1024 像素（正方形）
2. **去除背景**：保留纯透明或纯白背景
3. **亮度对比度**：调整确保所有细节清晰可见
4. **命名规范**：`character_001.jpg`, `character_002.jpg` ... `character_025.jpg`

### 标注文件

**自动标注工具**：BLIP-2 或 Caption Anything
**标注格式**：`[角色名], [性别], [年龄], [发型], [服装], [角度], [表情]`

标注示例：
```
character_001.txt: 沈栖月, 女性, 28岁, 黑色长直发, 白色西装套裙, 正面视角, 中性表情
character_002.txt: 沈栖月, 女性, 28岁, 黑色长直发, 白色西装套裙, 右侧45度视角, 中性表情
character_008.txt: 沈栖月, 女性, 28岁, 黑色长直发, 白色西装套裙, 正面视角, 愤怒表情
character_015.txt: 沈栖月, 女性, 28岁, 黑色长直发, 白色西装套裙上衣特写, 正面视角, 无表情
```

**人工修正要点**：
- 确保每个特征都被准确描述
- 角度描述必须精确
- 服装描述与实际画面一致

### 数据集质量检查清单

- [ ] 所有图片尺寸统一 1024×1024
- [ ] 背景已去除或统一为纯色
- [ ] 亮度/对比度一致
- [ ] 命名序号连续无缺
- [ ] 每张图都有对应的标注文件
- [ ] 标注内容与图片内容完全匹配
- [ ] 角色在所有图中身份一致（无 AI 错误残留）
- [ ] 覆盖了至少 6 个不同角度
- [ ] 覆盖了至少 4 种不同表情
- [ ] 包含了所有标志性细节的特写

## 训练参数设置（Kohya_ss 推荐）

### 推荐使用 Kohya_ss 训练工具

基础参数：
```
训练步数: 1500-2500 步（推荐从 2000 步开始）
学习率: 1e-4（标准起点）
批次大小: 1-2（取决于显存）
分辨率: 1024×1024
网络类型: LoRA
网络维度（rank）: 32-64（32 足够，64 更精细但更大）
网络 alpha: 16-32（通常设为 rank 的一半）
优化器: AdamW8bit
调度器: cosine_with_restarts
预热步数: 总步数的 10%
混合精度: fp16（节省显存）
```

### 训练后验证

**生成测试图**：使用相同的提示词，测试不同步数的 LoRA 版本。

**评估四维度**：
| 维度 | 评估方法 |
|------|---------|
| **相似度** | 与分解图中的角色是否一致 |
| **泛化能力** | 能否生成不同动作和场景（不只是训练图的复制） |
| **细节还原** | 服装、配饰、材质是否准确 |
| **无崩坏** | 极端角度下是否出现五官变形 |

**选择最佳版本**：通常是 1500-2000 步的版本。

### LoRA 文件优化

- 使用 Kohya_ss 的修剪功能，将文件大小压缩到 10MB 以内
- 测试修剪后的版本是否保持质量
- 命名格式：`[角色名]_v[版本号]_[步数].safetensors`

## 与其他方案的对比

| 方案 | 制作成本 | 一致性 | 泛化能力 | 适用场景 |
|------|---------|--------|---------|---------|
| 单张参考图 | 最低 | 60-70% | 差 | 快速测试 |
| 六视图锚定图 | 低 | 80-90% | 中 | 短视频/单集 |
| 全景分解图（无 LoRA） | 中 | 90-95% | 良 | 多集短剧 |
| **全景分解图 + LoRA** | **高** | **99%+** | **优** | **S+级/IP开发** |
