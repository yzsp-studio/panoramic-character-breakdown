# Layer 3: 头部与表情层规范

> **何时 read**：生成头部转面图、表情集、五官特写、口型图时。

## 核心目标

确保角色五官结构在任何表情和角度下都保持统一。
头部和表情是角色辨识度的核心——"灵魂的窗户"。

## 头部转面图（Turnaround Sheet）

### 六视图版（推荐）

清晰展示正面、3/4侧、侧面、3/4背、背面、另一侧面的头部造型。
确保发型、五官比例高度一致。

**排版**：1×6 横排或 2×3 网格，每格为头部+颈部+肩部上方。
**背景**：纯白/纯灰。
**光线**：均匀漫射光，无强阴影。

### 十二视图版（顶级配置）

在六视图基础上增加：仰视、俯视、抬头、低头、左倾、右倾。
覆盖头部在各种角度下的呈现。

**排版**：3×4 网格或 2×6 横排。

## 表情集（Expression Sheet）

### 基础表情清单（进阶配置）

推荐 6-9 种表情：冷漠/淡然 → 微笑/温柔 → 轻蔑/嗤笑 → 愤怒/严厉 →
惊讶/困惑 → 开心大笑 → 若有所思 → 悲伤/难过 → 害羞/窘迫

### 完整表情库（顶级配置）

20+ 种表情，覆盖所有基本情绪及其强度变化。
每种情绪 2-3 个强度级别（如：微笑 → 大笑 → 狂笑）。

### 排版规范

- 单图模式：≤7 种用 4+3 网格，≥8 种用 4+4 或三行布局
- 每个面板为**胸像**（头部 + 肩部），纯色背景
- 放大头部，强化表情细节的表现力
- 角色基础外貌在所有表情中保持一致

### 表情 Prompt 写法

描述每种表情的**肌肉状态**而非情绪词：
- ❌ `happy expression`
- ✅ `raised cheeks, crow's feet around eyes, upper teeth visible, relaxed brow, wide genuine smile`

面部肌肉描述要素：
- 眉形（raised/furrowed/asymmetric）
- 眼型（wide/narrowed/squinting/watery）
- 嘴角方向（upturned/downturned/pursed）
- 肌肉张力（tense jaw/relaxed cheeks/clenched teeth）

## 五官/面部特写（Facial Close-up）

对角色的关键面部部位进行像素级放大：
- **眼睛**：瞳孔颜色、虹膜花纹、高光点位置、睫毛密度
- **嘴型**：唇形、唇色、唇纹
- **鼻子**：鼻型、鼻翼宽度
- **耳朵**：耳型、耳饰
- **额头/下颌线**：面部骨骼结构

**排版**：各部位特写环绕头部正面图排列，引导线连接。

## 口型图（Mouth Chart）— 动画配音专用

定义角色在发出基础音节时的标准口型：

| 音节 | 口型描述 |
|------|---------|
| A | 嘴大张，下颌放松下垂 |
| E | 嘴微张，嘴角略向后拉 |
| I | 嘴微张，嘴角向两侧拉伸露齿 |
| O | 嘴圆形张开 |
| U | 嘴小圆形前突 |
| M/B/P | 双唇闭合，微微鼓起 |
| F/V | 上齿轻咬下唇 |
| L | 嘴微张，舌尖可见 |
| 静默 | 嘴自然闭合，中性状态 |

**排版**：3×3 网格，每格一个音节口型，标注字母。
