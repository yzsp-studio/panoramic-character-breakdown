## 🇬🇧 English

A character-blueprint workshop that turns a character description or reference image into a single comprehensive design sheet: a 16:9 canvas combining turnaround views (front/side/back), head-to-body ratio and height scale, a key half-body visual, extreme facial close-ups (pores/wrinkles/scars/makeup), an expression set with progressive battle damage, costume material breakdown (wear/weathering/texture callouts) and key prop close-ups (scratches/rust/use marks) — all in one image, ready as an AI-video character-consistency reference. It can also pull progressive visual changes (scars, wounds, blood, grime, costume damage, prop wear) straight out of a script or storyboard and carry the makeup progression through the expression set, e.g. light dust to bloodstains to full battle damage. Four output modes: single-sheet panorama (six-zone layout, recommended), basic six-view anchor sheet plus design board, advanced eight views with expression set and costume breakdown, and top tier eight-layer full breakdown with a LoRA training dataset.

### ✨ What it does

- Character description or reference image in → one six-zone comprehensive design sheet out
- Turnaround views, height scale and key half-body shot to anchor proportions
- Facial close-ups annotating pores, wrinkles, scars and makeup effects
- Expression set carrying progressive battle damage (light dust → blood → full damage)
- Costume and prop breakdown flagging tears, weathering, rust and use marks
- Four configuration tiers, with the top tier outputting a LoRA training dataset
